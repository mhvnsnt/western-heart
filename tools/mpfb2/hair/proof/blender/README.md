# Blender proof renders — HAIR phase (2026-11-02)

Blender 4.3.2 (Debian arm64 package), Cycles CPU, 20 samples, no denoise. Generated by `../../render_scene.py`
from the Blender-stage parts (`../../blender_fit.py`): every part is skinned to the template armature with its
transferred weights (Armature modifier) and carries its transferred shape keys, so a slider value set on the body
is set on the parts and a pose moves the hair by its weights. Jobs: `../../proof_jobs.py`; sheets: `../../proof_sheets.sh`.
Committed copies are 512 px / 256-colour (full-size 640–1024 px originals were rendered outside the repo).

- `sheets/01-template-bodies.png` — the 9 template bodies, front + 3/4.
- `sheets/02-body-morph-extremes.png` — each template at base / weight+ / weight- & tone+ / broad (shoulder width,
  chest, neck, traps +), with fitted hair + brows + lashes (+ goatee on the male bodies).
- `sheets/03-face-morph-extremes.png` — face neutral vs head width+ / brow height+ / head size+ / square jaw+;
  the fitted brows, lashes, beard and hairline follow through the transferred shape keys.
- `sheets/04-hairstyles.png`, `sheets/05-brows-lashes-facial-hair.png` — all 21 parts (generic names).
- `sheets/06-created-fighters-fight-stance.png` — three created fighters (template + sliders + parts + tint) in a
  hand-posed guard stance (spine/neck/head turned): hair follows head + neck/upper spine by weights.
- `bodies/`, `morphs/`, `parts/`, `fight/` — the individual frames.

Known look limits: MakeHuman hair is low-poly cards with an alpha texture (reads as a shell up close; the
long-straight style keeps the asset's centre tail strand); the hair frames were rendered before the final hair
colour / skin-tone material tweak (darker); stance is hand-posed bones, not a move clip.
