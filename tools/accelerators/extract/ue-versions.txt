# NOTES
# - Tekken 7 runs a heavily customized UE4; if umodel misdetects, override with
#   -game=ue4.21 / ue4.22 / ue4.27 until meshes load cleanly.
# - Encrypted paks: repak needs --aes-key; umodel reads already-unpacked trees
#   best (unpack with repak first, then point -path at the unpacked dir).
#   UModel does not take an AES key on the command line — unpack first.
# - UE5 .utoc/.ucas: repak handles them; umodel needs the matching -game tag.
# - When in doubt: `extract.sh cue4parse list <pakdir> --ue 5.3 --aes <key>`
#   to see what's inside before committing to a full export.
