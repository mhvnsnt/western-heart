Western Heart — WebGPU compute demo

Runs on the player's own device GPU — no cloud, no cost, no sign-in. Two real compute jobs, verified by reading results back to the CPU: (1) a vector-add (a + b = c, checked element-by-element), and (2) a particle update (gravity + floor bounce, 4096 particles) drawn every frame from the GPU buffer. This is the pattern a Three.js game would use for hit-spark / dust particles, cloth-ish motion, and post-processing passes — compute shaders replace per-particle JavaScript loops. If WebGPU is unavailable, this page says so plainly and does not pretend a CPU fallback is GPU compute (the canvas stays blank and the message below explains why).
