# game-hud UI kit (for the Creation Suite)

A complete game UI kit in pure HTML + CSS + vanilla JS — zero dependencies.
Health bars with damage ghosts, minimap, hotbar, boss bars, dialogue,
inventory, skill trees, and 60+ more components. One HTML markup, 12 CSS
skins; restyle everything by swapping a single CSS file.

- **Source:** https://github.com/threejsassets/game-hud
- **License:** MIT (see LICENSE-MIT.txt) — free for commercial use, keep the copyright notice.
- **What is here:** `dist/` (built CSS: `core.css`, `game-hud.css`, `layout.css`, `skins/` — 12 skins), `index.html` (component markup templates + skin style blocks), upstream README.md. Dev-only dirs (`references/`, `docs/`, `scripts/`) were NOT pulled.

## Skins (in `dist/skins/`)
Futuristic · Modern military · Sci-Fi · **Fantasy** · Horror · Pixel · Cyberpunk · Cartoon · Glass · Steampunk · Rust · Nature
