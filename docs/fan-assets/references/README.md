# References (links only — no rehosting)

Modeling + motion reference as **links**. Never claim a linked video is a WH asset.
Fair-use reference use only.

Creator motion from **TikTok, YouTube, and Facebook is approved as reference**
(owner 2026-10-14).

## Layout

- `by-character/<wh_id>.md` — e.g. `pantera.md`, `demonio.md`
- `by-move/<slot>.md` — e.g. `jab.md`, `sweep.md`
- `index.json` — machine-readable: character, move, url, platform, creator, notes

## Entry format

Each entry: URL, platform, creator handle, what to look for (stance, timing,
silhouette), and which WH character or move slot it supports.
