# V-System — Western Heart implementation (owner-approved 2026-10-22)

**Status:** IMPLEMENTED. All user-facing names are «name TBD» placeholders —
naming needs user approval (see §7).
**Teardown grounding:** Street Fighter V's V-System, community-documented
(V-Skill = MP+MK unique skill building V-Gauge; V-Trigger = HP+HK at full
gauge, timed install; V-Reversal = 1-bar guard cancel while blocking;
V-Shift = Season 5 HP+MK defensive shift, evade → slow-mo → Break window).
SFV teardown dir: `teardown/street-fighter-5/` (V-Trigger form-change noted
for Necalli in CAST-STATUS.md).

## 1. Design: Tekken-ified, one button

SFV spends three separate inputs on the system. WH keeps Tekken's input
language intact and maps the whole system onto **one new input** (`vskill`:
keyboard **V**, touch **V button**) plus block double-tap, dispatched by
context:

| Context | Input | Result |
|---|---|---|
| Neutral / calm | V | **V-Skill «TBD»** — per-character unique move, +4 souls on use, +soulGain on hit |
| Full meter (100) | V | **V-Trigger «TBD»** — 12s install: +15% damage, chip on all blocked attacks, V-Skill becomes armored EX |
| Blockstun + 50 souls | V | **V-Reversal «TBD»** — guard-cancel counter, strike-invulnerable through active frames, big knockback |
| Neutral, double-tap block | — | **V-Shift «TBD»** — 0.35s invulnerable backshift; evading an attack → 0.3× slow-mo + 1.2s Break window (+50% dmg, auto-CH) |

One button, zero conflicts with Tekken limbs. The meter is the existing
Nine-Soul meter (0–100) — the V-System is a *resource game* on top of it.

## 2. Meter economy (the actual game design)

100 souls can now be spent three ways — this is the decision the system adds:

- **Soul Surge** (existing): one-shot 18-damage cinematic super. *Now.*
- **V-Trigger «TBD»**: 12s install, ~+15% damage across the install, chip on
  everything, EX V-Skill. *Later, but more total.*
- **V-Reversal «TBD»** (50): the defensive spend. *Get off me.*

V-Skill feeds the meter (+4 on use, more on hit / parry), so the system is
self-priming: poke with the skill → earn the install → choose your spend.
This mirrors SFV's loop (V-Skill builds V-Gauge) without adding a second
meter to the HUD.

## 3. Per-character V-Skills (identity, not wallpaper)

`game/js/v-system.js` → `VSKILLS`. Data-driven; fighters not listed use the
default Soul Palm. Seeded kits:

| Fighter | V-Skill «TBD» | Kind | Identity |
|---|---|---|---|
| (default) | Soul Palm | strike | Lunging mid poke, safe meter builder |
| pantera | Iron Shoulder | armored strike | The grappler's armored way in |
| dio | Demon Lash | strike | Fast, rude, punished on whiff |
| ryusan | Vitriol Flick | strike | Fastest V-Skill, best meter build |
| phantom | Moon Catch | **parry** | 12f parry stance — catch a strike, stagger them, +12 souls |

Under V-Trigger every V-Skill becomes its EX: ×1.3 damage/knock + armor.
Parry-kind V-Skills never get a hitbox (`noHitbox`); their window
(`_vparryT`) is resolved in `game.js _resolveCombat`.

## 4. V-Shift details

- Input: two block-press edges within 280ms (`vshiftTap`), neutral only.
- 0.35s, fully invulnerable, travels 2.2m back.
- Evade detection: attacker in startup/active within 3.2m → proc: slow-mo
  (0.3× for 0.8 real seconds — the sim dilates, arena/camera stay live),
  1.2s Break window on the shifter. The next strike inside the window deals
  ×1.5 as an automatic counter hit, then the window closes.
- This is the same slow-mo mechanism the Reversal Edge proposal reuses
  (see PROPOSAL-REVERSAL-EDGE-2026-10-22.md §7).
