# Capcom 2020 Leak — Honest Access Assessment

**What it was:** ~1TB stolen via Ragnar Locker ransomware through an old backup
VPN at Capcom USA, November 2020. $11M ransom not paid.

**What was actually in it (verified via news coverage):**
- Staff/partner personal data (~390,000 people potentially affected)
- Release schedules (SF6, Dragon's Dogma 2, RE4 remake, MH Rise — all later confirmed real)
- Source code for OLD games (Devil May Cry 2, RE: Umbrella Chronicles, Tron Bonne 1999)
- Sales reports, financial info, business partner docs
- "Game development documents" (per Capcom's own statement — contents unspecified publicly)

**What it did NOT verifiably contain:**
Detailed Street Fighter 6 character production docs (design bibles, move design
documents, art direction materials). SF6 appeared in the leak only as a release
schedule entry. The detailed SF6 roster art leak was a SEPARATE incident in 2022,
heavily DMCA'd, and its contents were promotional art — not production docs.

**Access status:** Fragments circulated on 4chan/ResetEra (mostly dead threads).
Older-title source surfaces periodically on archive sites. Aggressive DMCA.
Cautionary note from prior research: leaked filenames became evidence in a $12M
copyright lawsuit against Capcom — downloading this material carries real risk.

**Verdict for Western Heart:** Documented for awareness. NOT pulled. The leak
does not contain the fighting-game character production documentation we need,
and what exists is legally radioactive. Our character production knowledge comes
from the tekkenmods community docs and public developer interviews instead —
which are better sources anyway (structured, legal, Tekken-specific).
