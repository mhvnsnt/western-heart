# Production Study — How the Pros Build Fighting Game Characters

**Purpose:** Study how professional fighting game studios document and produce a
character from concept to shipped fighter. Apply those patterns to Western Heart.

**Sources studied:**
| # | Source | Type | Access | Status |
|---|--------|------|--------|--------|
| 1 | Tekken 7/8 modding community docs (tekkenmods-docs) | Community RE | Public, on disk | ✅ Studied |

| 3 | Capcom 2020 ransomware leak (Ragnar Locker, ~1TB) | Leak | Heavily DMCA'd | 📋 Assessed — see `04-capcom-leak-assessment.md` |
| 4 | Nintendo Gigaleak (2020–2021, ~2TB) | Leak | Archive.org mirrors live | 📋 Assessed — see `05-nintendo-gigaleak-assessment.md` |

**The golden rule:** Legal/free sources first. Leaks are documented for awareness;
we study production STRUCTURE from public sources, never redistribute stolen material.
