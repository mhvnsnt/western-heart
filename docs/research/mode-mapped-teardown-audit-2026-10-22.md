## E. Open-source / free tools per mode (aggressive pull-ins)

- [ ] **T-01 — Rapier (MIT, WASM) — brawler physics.** Deterministic rigid-body physics compiled to WASM; pairs with Three.js. Use for: destructible props/debris (HMW-05), weapon physics (HMW-04), ragdoll-on-KO. Why: WASM speed for hundreds of debris bodies; determinism matters if brawler co-op ever goes online. Sources: rapier.rs; comparison verified 2026-10-22 (abratabia.com game-physics guide; three.js forum).
- [ ] **T-02 — cannon-es (MIT, pure JS) — physics fallback.** No WASM init, CDN-friendly, fully debuggable. Use where Rapier's WASM boundary gets in the way (quick prototypes, low body counts). Why: the three.js community's practical default; hackable when something misbehaves.
- [ ] **T-03 — Yuka (MIT) — brawler AI.** JavaScript game-AI library by a three.js maintainer: steering behaviors, pathfinding, state machines, perception. Use for: enemy AI, partner AI (HMW-02), crowd behavior. Why: purpose-built for three.js; covers exactly the AI a brawler needs.
- [ ] **T-04 — Howler.js (MIT) — spatial audio.** Web audio with 3D positional support. Use for: brawler hit SFX, positional crowd/weapon sounds, story-mode ambience. Why: the standard for game audio on web; trivial three.js pairing.
- [ ] **T-05 — Tone.js (MIT) — adaptive music.** Web Audio framework for interactive music. Use for: Nine-Soul meter stingers, BLAZIN'-style intensity shifts, story-mode score that reacts to fight state. Why: music that follows the fight is a "never been done" touch at this tier.
- [ ] **T-06 — ink / inkjs (MIT) — branching narrative.** Inkle's narrative scripting language + official JS port. Use for: story-mode dialogue, branching cutscene scripts, character endings. Why: the industry standard for branching game writing; writers (the owner) can author story without touching code.
- [ ] **T-07 — XState (MIT) — story/cutscene state machines.** Finite-state machines + actors for JS. Use for: cutscene sequencing logic, mission state, story chapter flow. Why: cutscene trigger/sequence bugs are state bugs; a real state machine kills the class.
- [ ] **T-08 — GGPO (MIT) — rollback netcode.** Open-sourced 2019 by Tony Cannon; the gold standard for fighting-game online (Skullgirls, SFIII:3SOE, Fightcade). Use for: versus online play. Caveat: C++ core — needs the WASM/JS port path (community ports exist, e.g. ggrs-style WASM builds); the game sim must be deterministic (fixed-point math) for rollback to work. Why: versus without rollback is dead on arrival for competitive play. Sources: en.wikipedia.org/wiki/GGPO (verified 2026-10-22).
- [ ] **T-09 — FModel / repak (free) — future extraction.** UE4 .pak toolchain already staged (`~/workspace/tools/tekken-decrypt/`). Use when SCVI/SFV binaries are acquired: character models, stages, UI, moveset data. Why: the extraction path is already proven for Tekken 7; it ports directly.
