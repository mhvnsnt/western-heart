## TTT2 DATA ARCHITECTURE (from landed docs on WH main `docs/tech/ttt2-mota/`, all read in full)
- **Motbins live in data006**: 66 blocks located by the string cluster `[NAME]\0CREATOR\0…`. Block base = (offset of bracketed name) − 0x20C. Section (ptr,count) BE u32 pairs at base+0x140+8i, 19 pairs, T7 order; **movelist = pair 12**; records 0x70 B big-endian.
- Two record rotations: **rotated** (most of roster): name@+0x4C, anim_name@+0x50, anim_ref@+0x54. **Unrotated** (Jun, Unknown = Kiloutre layout): name@+0x00, anim@+0x04, ref@+0x08. Jun's movelist is NOT in her header pairs: grid at block+0xA2D7C (rows tool JUN_GRID_OFF), motOrigin at grid record 589; Unknown's grid phase is section_ptr+0x2C.
- **The join: `anim_ref = (bank << 14) | index`** — pure function of anim_name within each character (Paul 1,290 distinct anims ↔ refs; Roger 1,262).
- **Bank 0** = character's own first trailing MOTA table inside data006 (Paul @ data006 0xD9C7C, 4 entries; Paul/Roger/Jun bank-0 sets are exactly idx 0–3, item anims). Shipped bake/rows tools do NOT wire bank 0 → bank-0-resolved slots are documented gaps, same as shipped production.
- **Bank 1** = one big MOTA table per character inside data005: Paul @0x140 (320) ×549; Roger @90,926,084 ×509; Jun @193,068,196 ×596; Unknown @198,828,228 ×736. Located by **clip-fingerprint matching** (entry type, track count, frame count, byte size; 0x64 frames = BE u16 at +(N·2+4), N = u16 at +2; 0xC8 frames = BE u32 at +4). Validation rates: Roger 68/89 vs Paul's table (next-best 24/89); Jun 35/41; Unknown 26/28 byte-identical vs Jun. Bank-1 indices are per-character and do NOT transfer.
- **Bank 2** = shared table in data004 @0x100 ×1,875; cross-character index agreement exact (922/922 Paul↔Roger shared anims).
- **MOTA entry access**: entry offset = table_offset + u32(data, table+16+4·idx); entry type BE u16 at entry: 100 = format 0x64, 200 = format 0xC8.
- **Decoders**: `tools/ttt2_mota_decode64.py` (0x64; sin/cos polynomial ZXY-Euler of raw i16 triples). 0xC8: BE raw floats. ~10% of 0x64 clips are unidentified encoder variants — report, never force. Valid body clip: ≥23 tracks, ≥2 frames, finite ≤1e4.
- **Record fields** (RECORD-FIELDS.md, validated Roger 2,197 + Jun 742 grid records): +0x10 = (char_id<<16)|(grid_index−23); +0x1C/+0x20 airborne start/end; +0x40/+0x44 first/last active frame; +0x5C attack word (low 16 bits; bit 0x400000 = own throw — Roger 15/15, Jun 6/6).
