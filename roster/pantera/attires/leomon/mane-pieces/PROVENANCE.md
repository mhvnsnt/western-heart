# Pantera Lion Mane — Provenance

## Source
**NOT procedurally made.** Cut from a real 3D Leomon model.

- **Game:** Digimon Links (mobile)
- **Source:** Models Resource — "Leomon / IceLeomon" model page
- **File:** chr072 (FBX was ASCII format, Blender can't read it — parsed via DAE with trimesh/pycollada)
- **Original mesh:** 3,923 verts, single skinned mesh
- **Extraction:** Separated spatially into mane, head+neck (sword excluded)

## Files
- `pantera-lion-mane-from-leomon-digimon-links.obj` — the mane (spiky golden ring)
- `pantera-lion-head-from-leomon-digimon-links.obj` — the full lion head + neck
