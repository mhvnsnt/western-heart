# Attire 4 — Pantera T7 P2 (wired)

The official Tekken 7 Player 2 color scheme, wired onto Pantera's Slot 1 base
GLB (`docs/tpose-refs/pantera-t7king/pantera-t7king.glb`).

**Source:** the P2 diffuse pack in `attires/p2/` (7 recolored `*_P2_D.png` maps,
`recolor_p1_to_p2.py`, `P2-preview.png` — verified in Blender 2026-10-12).
Only the 7 diffuse maps differ from P1; everything else (arms, gloves, mask)
is identical.

**Scheme:** black tights with bronze tribal designs, black trunks with bronze
KING logo, black boots with red trim and bronze studs, red/black gloves,
black panther mask with yellow eyes.

**Build (2026-10-18, Pantera custom-attires lane):** Slot 1 GLB with the 7
P2 diffuse PNGs swapped into the embedded images (same pixel dimensions,
texture-only — zero rig/geometry changes). No P2 model exists anywhere
(rigmodels.com checked 2026-10-12 — both T7 King models there are P1), so this
IS the official P2 as a texture swap of P1.

**Render:** `docs/tpose-refs/pantera-attire4-p2/p1_front.png` (T-pose, front,
locked orientation method, own-eyes verified).
