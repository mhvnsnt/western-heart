# BONUS CLASS — Index Canon

> **Class file, not a fighter.** "Bonus" is the roster class for fighters who stand **outside the soul structure** — not one of the Seven, not one of the Four, not counted in the twelve's devotional frame the way the core cast is. This file indexes the class; each bonus fighter's canon lives in their own file. The class's roster record is `roster/bonus/BONUS-CHARACTERS.md`.

In the bible's structure they stand outside the nine-souls arithmetic — the nine stay nine; the bonus class is the margin the arithmetic can't absorb, and the game is honest about keeping one.
