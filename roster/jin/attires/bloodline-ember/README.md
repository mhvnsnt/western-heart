# Jin Kazama — "Bloodline Ember" (Attire: first custom look)

The Bloodline Soul's devil-gene variant. Texture reskin only — no rig or
geometry changes. Built from `game/assets/models/jin.glb` (untouched on main)
by replacing 4 embedded PNGs (see `customization/reskin-library/jin/`).

- **Torso:** devil-gene flame-tribal marking across the chest, ashen skin
- **Pants flame decal:** orange/yellow → ember crimson
- **Pants:** deepened black, ember warmth in the weave
- **Obi:** cords gold → ember crimson
- **Eyes:** default brown kept; yellow tiger is a swappable option
  (`customization/parts/jin-eyes/`)

Renders (own-eyes verified 2026-10-18): `roster/jin/jin-bloodline-ember-front.jpg`,
`roster/jin/jin-bloodline-ember-side.jpg`.
