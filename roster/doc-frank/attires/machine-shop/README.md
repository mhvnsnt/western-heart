# Doc Frank — "Machine Shop" (Attire: first custom look)

The Builder Soul's machine-shop workwear. Texture reskin only — no rig or
geometry changes. Built from `game/assets/models/doc-frank.glb` (untouched on
main) by replacing 5 embedded PNGs (see `customization/reskin-library/doc-frank/`).

- **Shirt:** teal → dark brown work shirt
- **Tie:** rust → brass/copper metallic
- **Pants:** dark green → dark brown work pants (brown belt kept)
- **Shoes:** → oil-stained work boots
- **Eyes:** default blue-green kept; yellow tiger is a swappable option
  (`customization/parts/doc-frank-eyes/`)
