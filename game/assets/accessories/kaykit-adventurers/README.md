# kaykit-adventurers

27 fantasy weapons/props from KayKit's Adventurers Character Pack (free tier).

- **Source:** KayKit (Kay Lousberg) — https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0 and https://kaylousberg.itch.io/adventurers-character-pack
- **License:** CC0 1.0 Universal (see LICENSE-CC0.txt) — free for personal, educational and commercial projects, no attribution required.
- **Format:** GLB (single-file glTF 2.0). Upstream ships `.gltf` + `.bin` + `.png`; each was packed into a single GLB (binary + PNG textures embedded as bufferViews) and validated (glTF magic, JSON chunk, non-empty meshes, PNG magic on embedded images).
- **Files:** 27 GLB models.

## Contents
Swords: `sword_1handed`, `sword_2handed`, `sword_2handed_color` · Axes: `axe_1handed`, `axe_2handed` · `dagger` · Crossbows: `crossbow_1handed`, `crossbow_2handed` · `staff`, `wand` · Shields: `shield_round`, `shield_round_barbarian`, `shield_round_color`, `shield_square`, `shield_square_color`, `shield_spikes`, `shield_spikes_color`, `shield_badge`, `shield_badge_color` · `quiver`, `arrow`, `arrow_bundle` · `spellbook_open`, `spellbook_closed` · `smokebomb` · `mug_empty`, `mug_full`.

## Creation Suite slot mapping
`extra` slot (handheld weapons/shields). Shields also suit upper-acc/lower-acc as strapped gear.
