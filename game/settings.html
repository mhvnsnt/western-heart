ACCESS & ASSISTS

🜁 BUTTON REMAPPING

Remap Controls

Tekken-standard remapping. The virtual joystick is never touched (owner-approved) — remap face buttons and every other action. Tap a keycap, then press the new key.

🜂 TOUCH BUTTONS

Touch Button Layout

Reassign what each on-screen face button fires. Applies on next game load (the boot script rewrites the buttons before the input manager binds).

🜄 COLORBLIND OPTIONS

Color Vision

Colorblind-safe palettes (Okabe–Ito pairs, the modern-fighter approach): health bars, Nine-Soul meter, round pips, and P1/P2 markers. Applies instantly, everywhere.

🜏 DIFFICULTY ASSISTS

Assists

SF6 Modern-controls pull: execution help that never plays the game for you. All off by default. Your titles still count — the Trial respects effort, not purity.
