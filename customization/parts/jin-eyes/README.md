# Jin's eyes — swappable options

Tekken/WWE-style: every variant saved, never overwritten.

- `eye-original.png` — Jin's default brown eye (restore point, byte-identical to
  `game/assets/models/jin.glb` image 12).
- `eye-yellow-tiger.png` — the owner's universal "I like" variant: realistic
  golden tiger iris composited onto Jin's native eye texture (his own
  skin/sclera surround kept). Drop-in 128x128 replacement for `eye-iris`.

See `MANIFEST.json` for placement + swap procedure. Also wired into
`customization/eye-library/MANIFEST.json` character_mappings (`jin`).
