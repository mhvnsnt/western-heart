# Tekken 3 — UI Assets (AI Generation Templates)

These are extracted UI assets from Tekken 3 (PlayStation, 1997).
They serve as TEMPLATES for AI-generating Western Heart UI in the same style.

## Directory Structure

- `title-screens/` — Title screen art, logo treatments
- `character-art/` — Character portraits, select screen art strips
- `fonts-text/` — UI font character sets, text banners
- `menus/` — Menu backgrounds, mode descriptions, UI elements

## Usage

Per the owner's directive: "since our models are the base of their characters,
their art can be the base of our art." Use these as img2img bases or style
references when generating Western Heart UI.

## Source

Extracted from TEKKEN3.BNS TIM textures via `tools/local/tim_extract.py`.
See `../tim-inventory.json` for full 8,556-texture inventory.
