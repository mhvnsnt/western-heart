## 2. DirectionOffsets — the character-ID table

Root `<DirectionOffsets>`, 3 sections, 131 `<Offset>` entries total:

- **KakeaiOffset — 60 entries.** MainIDs in order:
  `0-17, 19-58` (58 solo entries — **MainID 18 is SKIPPED**) plus 2 tag-team
  pair entries at the end: `(MainID 9, SubID 27)` and `(MainID 27, SubID 9)`.
  Each solo entry holds `<Character MainID SubID="">` + 2x `<PlayerSide>`
  (each ~50 `<Stage>` x ~2 `<Layer no x y z r>` — per-stage tag-intro offsets).
- **EnbuOffset — 59 entries.** MainIDs `0-58` **all present, including 18**.
  (Enbu = intro performance; every character has one, even the mimic.)
- **ContinueAndSpecialOffset — 12 entries.** `<OffsetID>` + `<PlayerSide>` only,
  no `<Character>` — different structure, not a character table.

## 3. THE JOIN — MainID = BXML index (proven, not inferred)

Two independent anchors from the XML itself, matched against the map doc's
BXML table (`DATANNN-MAP-20261025.md` §4, 59 docs in file order):

1. **Tag pair (9, 27).** KakeaiOffset's last two entries are the tag-team pair
   MainID 9 + SubID 27 and MainID 27 + SubID 9. The only Jin/Devil Jin tag
   pair in the game. BXML#9 = `jin`, BXML#27 = `dvj` (Devil Jin). Both match.
2. **MainID 18 skipped in Kakeai, present in Enbu.** Mokujin (BXML#18 `mok`)
   has no tag-intro offsets because he mimics — but he does have an Enbu
   (intro) entry like everyone else. Exactly the pattern the XML shows.

**Therefore: MainID n ↔ BXML doc #n ↔ prefix ↔ character, for all n 0-58.**

  and joins BXML#47 `flw` (`flw_flw_hed_Kabuto`).
- **STILL OPEN `aki` (#30).** MVLT#30 (Dark Cyclone / Dark Buzzsaw) sits at the
  matching position but the name has no evidence in data000/data050.

  Peacock Waltz). If `gre` = True Ogre, then #31 may be Ancient Ogre
  (BXML#41 `ogr`) — but MVLT#42 also claims `ogr` under n-1. Unresolved.
- **STILL OPEN `bcv` (#58).** Last BXML doc; no MVLT list is clearly its match
  (57 lists vs 58 characters minus Mokujin = 57 — every non-Mokujin character
  has exactly one list, so `bcv`'s list is among the OPEN rows above).
