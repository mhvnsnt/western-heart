**Count note:** 59 playable on PS3/Xbox 360 (Tekkenpedia: "As of September 10th, 2012 there are 59 playable characters"; "at the final release, there were 60 playable characters" — the 60th counting Dr. Bosconovitch, Wii U exclusive). All 41 Tekken 6 fighters return (incl. Panda as a full separate slot), plus returning favorites (Jun, Michelle, Kunimitsu, Ogre, True Ogre, Angel, Jinpachi, Forest Law, Prototype Jack, Alex, Tiger Jackson, Violet) and 3 newcomers (Jaycee, Sebastian, Slim Bob).

## Chimera Build value
- **Deepest reskin pool of any chimera source:** 59 distinct fighter bases; every body type from Kuma/Panda (bears) to Jack-6 (robot) to Slim Bob (obese) to Alisa (cyborg).
- **~120+ attire variations** across the roster (P1/P2 + customization slots).
- Alter-ego slots (Jaycee/Tiger/Violet/Alex) = the template for Western Heart alt-persona fighters.
- Combot = reference for a create-a-fighter system (Fight Lab).
