### What's inside (structural interpretation)
TTT2 runs on Namco's in-house engine (NOT UE4), so the game data lives in proprietary containers:
- **Character data / models / movesets / audio / textures** — all inside the 52 `DataXXXX` chunks plus the 7 large `00000002/` blobs. The 52 equal-sized chunks are an STFS multi-part content package; real file boundaries (models, movesets, stage data, audio banks) are only visible after STFS decryption + inner-container parsing.
- **Movesets:** TTT2-era Namco fighters store movesets as per-character move-list binaries inside the main data package (same family as Tekken 6's console format, distinct from PSP GMO).
- **Audio:** XMA-encoded audio banks inside the Data chunks.
- **Textures:** Namco X360 texture containers inside the Data chunks.
- No plaintext roster/stage manifest exists at the package level — all names are inside the encrypted/encoded containers.
