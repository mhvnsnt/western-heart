## Asset Paths (from tekkenmods-docs)

- Character assets: `TekkenGame\Content\Characters`
- Stages: `TekkenGame\Content\Maps` + `TekkenGame\Content\Stage`
- UI: `TekkenGame\Content\UI_common`
- Audio: `TekkenGame\Content\WwiseAudio`
- PAK files: `TekkenGame\Content\Paks`

## File Prefixes

| Prefix | Type |
|--------|------|
| SK | Skeletal Mesh (character models) |
| SKT | Skeleton (rig structure) |
| SM | Static Mesh (environments/props) |
| BP | Blueprint (game logic) |
| PA | Physics Asset |
| CS | Character Set (customization data) |
| CCI | Customize Character Item |
| CI | Character Item (equippable) |
| EI | Extra Item (weapons/props) |
| M / MI | Material / Material Instance |
| T | Texture |

## Customization System

Tekken 7's customization uses CCI (Customize Character Item) and CI (Character Item) assets. Each character has a CS (Character Set) defining available customization slots. This is the system to study for Western Heart's WWE-style attires.
