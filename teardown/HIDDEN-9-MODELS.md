## Verdict up front — the spec was wrong

The spec (§7) said 8 of the 9 hidden fighters have no model. **That is false as a file-existence claim.**

- **The 9 hidden roster entries are 8 souls + 1 non-soul.** The souls: RIN, BYOU, TOU, SHA, KAI, RETSU, ZEN, GYOU. JIN (the 9th soul) is NOT hidden — JIN fights as Phantom, pickable. RYUJI is not a soul at all.
- **Among the 8 hidden souls, only BYOU has no model file of any kind anywhere in the repo** — no own-name file and no base-character file (Wang Jinrei has no model file anywhere).
- **No own-name file, but base-character models exist unwired: 1 — TOU** (Paul models in the Godot lab + T3 teardown).
- **Own-name rigged body that PASSED the repo's loader gate: 4 — RIN, SHA, KAI, RETSU** (all with MODEL_URLS keys already).
- **Full wired models: 1 — ZEN** (12 files, MODEL_URLS wired, rigged 2026-10-22).
- **Source files only, all unrigged: 1 — GYOU** (7 Tripo statics, archive-only).
- **RYUJI is not a soul and not a model-less soul.** It is the pure-Yamazaki duplicate entry of CORNERSTONE (which HAS a model, `roster/ryuji-rock/`), hidden under the owner no-duplicate law — not under the soul rule. Canon says the entry "is untouched and stays in the repo"; no canon requires giving it a model or unhiding it.

So **7 of the 8 hidden souls have model files of some kind in the repo.** What most of them actually lack is a `model` field in the roster + a grid slot — a wiring/config gate, not a missing file. The fix for most is config (and one rig job), not new models. Only BYOU has no file at all — and per canon BYOU is **not supposed to have a body of its own** (see BYOU row): a soul has no body of its own; it fights through its vessel, Zui, who HAS a body.

The 2026-10-22 owner-directive comment in `select-screen.js` ("the seven VESSELED souls… have no bodies of their own yet") is also wrong as a file-existence claim: the `-body` files passed the loader gate on 2026-10-17/18, **before** that directive was written. Same comment says "Only ZEN and GYOU stay selectable as spirit fighters" while both are IN `SELECT_HIDDEN` — wrong for both.

## What "no model" actually means here — three different things were conflated

1. **Roster `model: null`** — the fighter's roster entry names no model. True for 8 of the 9 (all but ZEN).
2. **No MODEL_URLS key** — the game cannot load a model by key. True for the fighters' own ids (no `rin`/`byou`/`tou`/`sha`/`kai`/`retsu`/`gyou`/`ryuji` keys) — BUT `rin-body`, `sha-body`, `kai-body`, `retsu-body`, `zen-body`, `jin-body`, `pantera-body` keys DO exist and are wired.
3. **No model FILE in the repo** — true for only **1 of the 8 hidden souls (BYOU)** — no own-name file and no base-character file (Wang Jinrei has no model file anywhere). RYUJI also has no file, but RYUJI is not a soul.

The spec treated (1) as (3). The actual work to unhide each fighter is in the table's last column — mostly one-line roster/config changes, one rig job (GYOU), one convert/rig (TOU's Paul), and **no model build owed at all for BYOU** (canon: BYOU fights through vessel Zui) **or for RYUJI** (canon: the entry stays untouched; it is not a soul).
