# Tekken Model Library — Master Index

Every Tekken character model pulled into the Western Heart chimera build, across all
three batches. Locations follow the safe-storage pattern: small files live in the repo,
large files live on GitHub Releases (they're too big for git).

- **Batch 1** — committed to the repo: `teardown/models/tekken7/`

(The only established Western Heart roster name in this set is King → **Pantera**.)
