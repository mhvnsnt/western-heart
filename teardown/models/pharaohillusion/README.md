## Format notes

- `.mesh` = XPS binary mesh; `.mesh.ascii` = XPS ASCII mesh (same geometry, human-readable)
- Textures are TGA (diffuse, normal, specular, light maps)
- `.pose` files are XPS poses
- Import into Blender via the XNALara/XPS importer addon, or parse `.mesh.ascii` directly
